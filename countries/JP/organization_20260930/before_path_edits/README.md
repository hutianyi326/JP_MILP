# Country Investigation

欧洲电力市场规则、平衡市场机制与独立储能交易优化研究项目。

## 项目目标

本项目建立一条可复用、可追溯的研究与建模链路：

1. 收集并分析各国（以欧洲为主）的电力交易规则和平衡市场交易规则。
2. 研究日前、日内、平衡容量、平衡能量及不平衡结算的申报、出清、定价与结算机制。
3. 整理相关市场的价格、成交、激活和结算数据来源。
4. 分析独立储能参与现货与平衡市场的交易策略。
5. 建立 MILP 优化模型，明确输入、输出、约束和结算逻辑。
6. 先完成历史数据下的收益测算，再逐步过渡到预测价格驱动的交易模拟。

## Agent 架构

项目采用“主线程 + 两个同级专业 Agent”的单层结构。专业 Agent 不得创建下级 Agent。

### 主线程

- 模型：`gpt-5.6-sol`
- 推理强度：`high`
- 职责：确定研究范围、拆分任务、审核研究证据、批准建模、处理跨模块争议并验收最终成果。

### `market_researcher`

- 模型：`gpt-5.6-luna`
- 推理强度：`xhigh`
- 职责：
  - 查找监管机构、TSO、交易所、NEMO 等官方资料；
  - 研究现货、平衡与不平衡结算规则；
  - 提取市场准入、申报、出清、定价、激活和结算机制；
  - 识别独立储能的参与条件和限制；
  - 整理价格、成交量、激活量和结算数据来源；
  - 按统一模板形成国家研究成果。

### `modeling_engineer`

- 模型：`gpt-5.6-luna`
- 推理强度：`high`
- 职责：
  - 设计储能交易策略和市场组合；
  - 编写 MILP 数学模型和输入输出规范；
  - 实现数据校验、结算引擎、优化模型、求解、回测和报告；
  - 编写测试并诊断模型或结算异常；
  - 将已确认的国家规则映射为国家配置，而不是在通用模型中硬编码国家判断。

## 模型路线

### 阶段一：历史结果测算

阶段一包含两个递进步骤：

1. **历史结算重演**：给定历史价格、市场结果和一组既定调度，验证结算公式及收入分项是否能够准确复算。
2. **完美信息优化**：将历史期间的实际价格、激活和结算结果作为已知输入，计算储能在完美预知条件下的事后最优收益。该结果是理论上限，不等同于可执行回测。

### 阶段二：预测价格模拟

1. 决策时只向优化模型提供当时可获得的预测价格和已知参数。
2. 交易决策生成后，使用实际出清价格、实际激活和实际结算结果计算收益。
3. 若平衡市场容量需求、中标概率或激活预测数据暂不可得，先使用明确记录的历史统计或情景假设。
4. 天气、负荷、风光出力等信息可以先用于价格预测，不要求直接进入储能 MILP。

## 核心原则

- 关键研究结论必须能够追溯到官方来源、文件日期和原文位置。
- 官方规则事实、研究解释和建模假设必须分开记录。
- 市场研究经过主线程确认后，才能进入策略和模型阶段。
- 预测决策与实际结算数据必须分离，防止未来信息泄露。
- 通用模型保持国家无关；国家差异通过 `model/country_configs/` 配置。

### 政策文件提取约定（DE-09，2026-08-03）

`countries/DE/sources/extracted/` 中的提取 MD 采用统一模板：元数据（来源、版本、
SHA-256）→ 章节页码地图 → 关键条款摘录（规则事实，带页码）→ 研究解释 →
建模假设 → 与已有研究文件的对应 → 待确认。原始 PDF 以 `reference/` 为权威版本，
提取 MD 是派生索引，不替代原文。后续 agent 写研究或建模前，先读对应提取 MD
定位章节，再回原文核对。

## 推荐工作顺序

1. 在 `project/scope.md` 中确定本轮国家和市场范围。
2. 使用 `project/research_template.md` 完成国家研究。
3. 由主线程审核证据并更新 `project/country_status.yaml`。
4. 在 `model/strategy.md` 与 `model/milp_formulation.md` 中完成策略和数学模型。
5. 根据 `model/input_output_spec.yaml` 实现代码与数据校验。
6. 运行历史结算重演、完美信息优化和预测价格模拟，并将结果写入 `outputs/`。
