# 日本MILP：统一日前采购代理与西班牙式激活数据规范

版本：2026-09-30 / 本轮确认稿  
性质：用户已确定的建模基线＋实施建议＋数据采集规范。本文为增量说明，不覆盖原始日本MD，不表示代码已实现或回测已通过。

## 0. 适用范围与来源层级

本轮用户确定：

1. 2025年及以后历史测算不采用真实周采购GCT，统一按EPRX日前采购名义时序模拟；结果必须说明这一限制。
2. 日本主激活代理与西班牙当前v2.0一致，采用满方向容量的等效时长，顺序为“下调→上调→基线”。日本物理基本格仍为30分钟。

既有用户决定保持：单成员LV标签实例2 MW/8 MWh、EHV实例100 MW/200 MWh；不建模产品准入；循环资源采用西班牙政策；现货主基线同事件买卖同价、单个净交易变量；冻结和新增现金统一求和；主收益不含imbalance。

来源优先级：本轮用户决定优先于原日本文件中冲突的周GCT和激活代理条款；西班牙以文件末尾v2.0为参照，不恢复前半部旧情景树。新增多通道同步方法、数据质量检查和示例属于本说明的建模建议，不是EPRX规则原文。

## 1. 统一日前采购代理

### 1.1 名义事件时间

对交付日D的容量订单，统一使用JST：

| 事件 | 模型采用时刻 | 性质 |
|---|---|---|
| JEPX日前关门 | D−1 10:00 | 沿用研究文件事件模板 |
| 日前结果 | 采用已定义的日前结果节点，并须在容量GCT之前 | 不将GCT等同结果时间 |
| EPRX容量GCT | D−1 14:00 | 全历史统一名义假设 |
| EPRX容量结果节点 | D−1 15:00 | 全历史统一名义假设，不重演实际延迟 |
| JEPX时间前 | 按所选日内事件模板 | 不因本轮变更增加任意可交易节点 |

“日前采购一致”指EPRX的日前采购顺序，不是把容量GCT也改成JEPX的10:00。

求解和冻结使用`model_gct/model_result_time`。原始可取得的`historical_gct/historical_result_time`只用于追溯；未取得原始周时间不阻止本反事实模型，但不能捏造为真实值。既有真实项目冻结订单不能被转换成新可变订单；如使用真实订单，必须另行标记其混合情景性质。

### 1.2 滚动执行

沿用西班牙：两日规划、仅首日执行；冻结当日GCT到期的订单，包括明日交付的订单。下一轮承接执行SOC、已用年度EFC及冻结账本。普通窗口末不硬重置SOC；正式终点施加既定终端SOC，正式终点后提供一个当地日输入，观察日现金不计正式收益。

不再因为历史周采购时间而建立周报价模块、外部周容量或周经济前视。该删除不代表取消物理功率、SOC、服务持续能力或已有承诺约束。

首个正式日采用西班牙的既定初始化：过去已关门而没有输入历史承诺的订单，不事后补报。需要预热时，应显式定义预热区间和不计收益规则，不能隐藏补单。

### 1.3 不随GCT简化改变的内容

- 历史原生3小时/30分钟商品交付块。
- 原始价格、原始报价单位、价格适用日期及来源。
- 容量1 kW刻度、最低新报价量及容量共享/非共享结构。
- 电池功率、SOC、效率、循环资源及已确定的服务能力约束。
- 当前已选产品范围；不重新增加准入审批模块。

对原生3小时块b：

\[
R_{t}=R_b,\qquad t\in T_b,\quad |T_b|=6.
\]

它在D−1一次决定，六个半小时共享同一个容量决策；不拆成六个自由容量变量，不把MW除以6。

本轮改变的是报价和冻结时间，不是交付持续长度或全国历史价格形成机制。

### 1.4 必须随结果呈现的限制说明

> 本测算采用统一日前采购代理：将研究期内原按周采购的EPRX商品，其报价关门与结果节点替换为交付日前的名义节点，同时保留历史原生商品块与参考价格。原周采购价格仍作为外生历史输入，并未按反事实日前市场重新出清。因此，结果反映统一日前承诺条件下的理想化储能交易毛收益，不是原历史周采购规则下的可执行策略重演，也不能直接用来衡量实际制度改革收益。测算还采用西班牙式三相位激活代理，不重演真实秒级指令顺序；主收益不含imbalance及已声明排除费用，不是项目净利润或保证可实现收入。

推断边界：推迟决策节点通常提供更多临近交付的调整自由，但在不同窗口/约束/激活代理下，不能据此宣布所有结果必然更高或形成严格收益上界。

## 2. 西班牙式激活代理在日本的定义

### 2.1 单一物理调用通道

日本基本格t长为\(\Delta_t=0.5\)小时。外生强度满足：

\[
\alpha_t^+\ge0,\quad\alpha_t^-\ge0,\quad\alpha_t^++\alpha_t^-\le1.
\]

等效相位时长：

\[
\tau_t^-=\Delta_t\alpha_t^-,\qquad
\tau_t^+=\Delta_t\alpha_t^+,\qquad
\tau_t^0=\Delta_t(1-\alpha_t^--\alpha_t^+).
\]

固定顺序：下调→上调→基线。仅创建正时长相位，零时长相位省略。

令\(R_t^+,R_t^-\)为对应物理方向能力，而不是默认两项日本容量采购变量。单产品可由固定方向系数\(h_t^\pm\)映射：\(R_t^\pm=h_t^\pm R_b\)。未建模准入不等于可以忽略此物理方向定义。

忽略辅用和端口差异的展示式为：

\[
P_t^-=B_t-R_t^-,\quad
P_t^+=B_t+R_t^+,\quad
P_t^0=B_t.
\]

\[
E_{t,\ell}^{end}=E_{t,\ell}^{start}
+\eta_c c_{t,\ell}\tau_{t,\ell}
-\frac{d_{t,\ell}}{\eta_d}\tau_{t,\ell}.
\]

相邻相位和相邻半小时必须连续；不得每半小时重置SOC。原模型保留的AC/DC辅助用电，继续在各自端口扣除，不重复扣。

物理激活量：

\[
A_t^{phys,+}=\Delta_t\alpha_t^+R_t^+,\qquad
A_t^{phys,-}=\Delta_t\alpha_t^-R_t^-.
\]

幅值已经是完整方向容量，不再乘一次alpha，否则成为alpha平方。

### 2.2 多产品并存：共用一条电池时间轴

前四类复合产品的共享容量，不应为每个内含产品复制同一物理激活。应先定义去重后的独立`activation_channel_id`，并登记其与`capacity_group_id`的关系。

多个独立通道各有不同alpha时，分别形成完整半小时的三相位，然后对齐到共同时间轴，而不是依次运行多个半小时。建议方法：

1. 对每个通道a生成固定边界\(0,\Delta\alpha_a^-,\Delta(\alpha_a^-+\alpha_a^+),\Delta\)。
2. 对所有通道边界取排序并集，得到共同子段。
3. 在每个共同子段使用各通道所在相位，叠加实际功率；只递推一条电池SOC。
4. 相位边界只依赖外生alpha，方向容量仍线性进入功率，因此保持MILP。

两个独立通道在一般情形至多产生5个正时长共同子段；这保留“每通道三相位”的经济代理，但不强求整个电站永远只有3段。共同半小时起点对齐也是新增同步假设，不是已知真实指令相关性。

若复合模式的物理调用不可分，应直接输入完整模式的联合调用代理，而不是用各产品边际统计相加。若结算按合并/净化后的认可量计算，也不能将相互抵消的通道毛量各自重复付费。

禁止：根据优化变量计算\(\alpha_{eff}=\sum_a\alpha_aR_a/\sum_aR_a\)，再把它作为外生固定相位时长。该操作一般会使时长依赖决策，破坏原有线性结构并改变可行域。

### 2.3 付费层不因物理代理而改变

\[
A_t^{pay,\sigma}=\chi_t^\sigma A_t^{phys,\sigma},\qquad
\Pi^{act}=\sum_{t,\sigma}\pi_t^{A,\sigma}A_t^{pay,\sigma}.
\]

价格已统一为有符号收入系数时，下调不再重复取负。物理电量不是默认全部有独立付款资格。原日本文件的一次-only付费开关由适用口径决定；即使该开关为0，实际响应、损耗、SOC和EFC仍计算。本轮选择三相位不等于确认所有产品chi=1。

## 3. 需要补采的数据：目标粒度与用途

最低目标粒度为“30分钟×区域/资源池×产品或去重后的调用通道×方向”。数据在原生商品块和结算端口之间可追溯。按现有研究报告，容量量价和JEPX价格已有记录，真实激活是主要未闭合项；本说明没有重新验证全部既有数据文件。

| 数据 | 最低目标粒度 | 建议字段 | 是否新增重点 |
|---|---|---|---|
| 参考中标/有效能力 | 原生商品块，映射每30分钟；产品/池/方向口径明确 | award_mw、reference_up_mw、reference_down_mw、native_block_id | 对既有容量数据补口径与映射 |
| 物理毛上调电量 | 30分钟×池/通道 | activated_up_mwh | 必须补 |
| 物理毛下调电量 | 同上，不能只用上下相抵净值 | activated_down_mwh | 必须补 |
| 认可付费电量/开关 | 30分钟认可量，或有生效期的合同映射 | paid_up_mwh、paid_down_mwh、chi_up、chi_down | 付费产品必须有一种合格映射 |
| 有效调节电量价格 | 30分钟；或适用该格的有效报价/合同价 | up_price_jpy_mwh、down_signed_price_jpy_mwh | 有付费激活时必须补 |
| 调节现金对账 | 30分钟×方向；可用于推导有效价 | activation_cash_jpy | 价格无法直接取得时的替代来源 |
| 基线与实测功率 | 只有缺少可靠毛方向电量时才需要；尽量原生秒级/分钟级 | timestamp、baseline_mw、actual_net_mw、command_mw | 用于推导物理激活，不作为全部实例额外门槛 |
| 一次频率响应数据 | 有可靠30分钟毛量则不强求；否则优先原生约1秒频率/功率与控制参数 | frequency_hz、frequency_area、deadband、droop/gain、filters、limits | 一次缺失毛量时的工程代理来源 |
| 容量共享/调用映射 | 模式级静态元数据＋半小时生效范围 | capacity_group_id、activation_channel_id、component_role、payment_pool_id | 复合和多产品并存必须清楚 |
| 来源与版本 | 每个文件/记录 | raw_unit、interval_start/end、source、revision、publication_time、quality | 必须保留 |

这里“1秒”是建立/验证一次响应代理时的建议采样目标，不是本规范重新规定的市场准入或认证要求。已有合格半小时毛方向电量时，三相位MILP不需要全年秒级数据。

### 3.1 alpha生成

若参考能力\(Q_t^{ref,\sigma}>0\)在该半小时内按所声明代理保持不变：

\[
\alpha_t^\sigma=
\frac{A_t^{ref,phys,\sigma}}{0.5Q_t^{ref,\sigma}}.
\]

分子必须是物理毛方向电量，分母必须对应同一池/同一方向的有效能力。它不是投标需求、全部装机或容量收入中标概率。日本不存在可自动照搬的独立下调中标列时，应明确建立下调物理参考能力，不能把上调量不加说明地复制到下调。

参考样本可以是系统、资源池或同类项目；其映射到本站的可缩放性属于建模假设。本站优化量R不用于反算外生alpha。

已取得经过核验的半小时alpha，也可直接导入，但应保存原始分子、分母或其来源和定义。

参考能力在格内改变时，优先按原始生效时间拆分/积分，不将首值直接用于全格。需要改用加权容量代理时，明确记录这一额外假设。

### 3.2 由高频数据推导毛电量

相对正确无调节基线的响应功率为\(r_s\)，原始时间间隔\(\delta_s\)以小时计：

\[
A_t^+=\sum_{s\in t}\max(r_s,0)\delta_s,\qquad
A_t^-=\sum_{s\in t}\max(-r_s,0)\delta_s.
\]

不能仅用“实发减日前计划”作为所有激活，因为其中可能包含后续计划更新和普通偏差；应使用对应有效基线与指令/计量归属。

若数据已是毛MWh，则直接按时间求和，不再乘0.5。若是半小时平均方向MW，才乘0.5。更细频率/功率先正负分解再积分，不能先平均成半小时净值再取正负。

### 3.3 有效能量价格

高频有价格与认可电量时：

\[
\bar\pi_t^{A,\sigma}=
\frac{\sum_{s\in t}\pi_s^{A,\sigma}A_s^{pay,\sigma}}
{\sum_{s\in t}A_s^{pay,\sigma}}.
\]

不能以简单时间均价替代电量加权价而声称精确还原现金。若只有同范围方向现金和付费电量，也可推导对应有效价格；付费电量为0时，此价格比值未定义，不强制填0。月度价格只能作为单独价格代理，不是半小时实际结算价格。

### 3.4 覆盖期

从用户选择的2025年以后正式起点覆盖至正式终点，并额外覆盖终点后一个完整JST观察日。日内若只有全日事后均价，不能假装不同事件都有独立可成交价格；当前理想事件假设须单独登记。

## 4. 公共数据核查与主要陷阱

### 4.1 EPRX容量记录不是完整能量结算输入

EPRX FAQ说明，公开交易实绩单价为ΔkW价格，不含V1/V2。其还说明，TSO指令电量难以分离市场采购与余力活用合同来源，无法按商品独立发布相应调节电量单价。因此不能预设五个产品都有可直接下载的完整半小时能量量价API。

建议优先核查属地TSO、交易商、聚合商或项目结算导出的粒度和归属；本次未核实九区、五产品全量来源，也没有获取缺失的激活历史。

系统/项目/资源池口径不可混用。EPRX“电源属地别”与“TSO别”不是同一个地域口径；选择其中一种作分母时，要核验激活分子的匹配范围。

### 4.2 三次②公开“使用率”不是实测激活率

EPRX该页面定义：

\[
使用率=\frac{FIT预测误差实绩}{必要量},
\]

并进行取整及0%—100%显示处理。它不是本规范的\(A^{phys}/(Q^{ref}\Delta)\)。不能将其直接改名为“实际激活率”，更不能推广到其他产品。

该数据可以另建`fit_forecast_error_utilization_proxy`情景，但必须说明不是实测指令电量/付费电量，并保留公开百分比舍入与截断的信息。

### 4.3 一次数据

优先取得同类资源的半小时毛上下响应量和参考能力。缺少时，可由所属频率区高频频率、声明的控制增益/死区/滤波/限幅生成工程响应，再汇总至半小时。仅半小时平均频率不能恢复正负摆动、响应绝对电量和损耗。

“没有独立电量付款”不允许把一次alpha置零。不能使用二次①代理自动填一次。没有合格数据时保留未知或明确合成情景。

### 4.4 数据取得方式

优先使用官方提供的批量CSV/ZIP和已授权导出。EPRX公开页面注明自动大量抓取需要事前许可；商业使用也有条件。本文不提供或声称已经验证可匿名使用的完整交易API。

## 5. 必须执行的数据质量检查

| 检查 | 处理原则 |
|---|---|
| Q>0且真实毛电量为0 | alpha可确认为0 |
| Q=0且毛电量>0 | 分母范围、来源或通道不匹配；不得封顶修复 |
| Q=0且毛电量=0 | 比值未定义，不能视为可靠零调用样本 |
| alpha方向为负或两方向和>1 | 三相位前提不满足；追查口径或另立代理，不自动归一化 |
| 只有净电量 | 不足以推导毛上下量 |
| 只有3小时激活电量 | 不足以还原六个半小时；均分只能单列合成分配情景 |
| 3小时中标容量 | 六个半小时保持同一个MW量，不除以6 |
| 3小时容量价格 | 按原始价格单位判断：每半小时价不再除6；整块总单价才按选定核算分配 |
| 复合内数或跨区重复 | 先按官方记录/声明模式去重，不能相加制造容量或电量 |
| 未付费模式 | 物理数据仍必需；未确认的付费映射不能默认为1 |
| 能量价格缺失 | 不能以imbalance价静默替代；不存在付款或确认激活为0的记录按对应依赖单独处理 |
| 观察日缺字段 | 显式质量标记，不假装完整两日前视 |

不把缺失价格、激活或能力填成0后宣称为真实回测。数据不可用只禁用相应需要它的产品/时段，或转为单独标注的合成情景；已有冻结非零承诺覆盖缺口时应报告状态冲突，不能删除旧义务。

1. 原生3小时容量块20 MW映射六个半小时：六格均20 MW，只有一个容量自由决策；统一日前GCT只冻结一次。
2. 参考上下能力各100 MW，半小时物理毛上调10 MWh、下调5 MWh：alpha分别0.2、0.1；相位顺序下3分钟、上6分钟、基线21分钟。
3. 用例2中本站方向能力各20 MW：毛上调2 MWh、毛下调1 MWh；不再乘一次alpha或0.5。
4. 只提供净电量5 MWh，不能自动认定毛上调5、毛下调0。
5. 一次chi=0且alpha非零：调节电量现金为0，但物理SOC/EFC仍发生变化。
6. 三次②公开使用率数据不得标记为metered_activation；使用它时必须为独立代理情景。
7. alpha之和1.2：不得截为1继续当作历史三相位；原记录保留异常。
