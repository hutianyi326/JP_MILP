## 研究解释

电源属地均价与TSO均价口径不同；使用前者作为九州资源价格代理。平均成交价不等于本站可成交报价，区域成交量不自动构成本站中标容量限制。正式行情全部采用确报；9月1日速報仅用于观察。3月拆分文件在适用日范围外的填零行先验证全区域均为零、空或横线，再排除，不能当作正式市场零价。

真实零价且成交量大于零的行情有效；零成交量的原始零值保留，但研究输入价格为null；缺失成交量、正成交量却缺价格、缺少整格均阻断组装。不存在普通一次、TSO均价或其他地区回填。

## 建模假设

- 沿用用户确认的LV等效资源：2 MW/8 MWh、DOD95%、SOC0.4—8 MWh，初始及每日期末4 MWh，充放电单向效率92%，并网进出各2 MW、零辅用、无额外线路损耗。只参与一次离线，不作日内套利；每天恒定恢复基线，允许按九州现货代理价补电或处置余电。
- 一次调用现金为零，调用电量仍影响SOC、损耗和循环；控制死区±0.01 Hz、满响应±0.20 Hz、双向满功率5分钟为沿用工程假设，不是本次官方认证的本站设置。
- 频率正态等效代理：均值取公表半小时均值，尺度 `s=(U-L)/4`，不是把公表区间当严格置信区间或证明真实正态。保留原始三字段；均值绝对值大于1Hz时隔离整日，未自动纠正原值。本轮未发现此类隔离日。
- 6,020个正式格有观测统计，7,132格缺失。缺失格在九州正式可用样本中，严格匹配半小时时段与工作日/周末/法定假日类型，再取区域负荷绝对差最近5格，时间升序破同距离，等权平均均值和尺度。观察日不进入供体池；9月1日48格亦代理。该方法是参数平均，不是混合分布方差拟合。频率代理倍率1，无其他敏感性。所有供体、权重、负荷差留表。
- 冬季向春夏样本迁移以及广域运行前后的同分布性未经实证；代理可能低估或高估调用与恢复成本。所有后见供体和最终价格都仅用于事后条件测算，不能声称决策时已知。
- 无属地离线成交价时禁止新增容量报价是保守假设，不是官方禁投；有价格时理想全额成交且无价格冲击。期初已关门且无已给定初始承诺的合同为零；历史名义时钟不表示异常公告已逐次核实。
- 每年600 EFC按正式天数分别折算：2025年31天、2026年243天，SOC与已冻结合同跨年连续。报价最小1 MW、网格0.001 MW沿用模型口径。
- **全期为等效资源的条件性反事实。2026-03-14前不主张真实低压准入；之后也未验证本站聚合、计量、通信、履约和合同资格。** 报告另列准入日期前后分段。
- 不含偏差结算、投资、固定运维、衰减更换、税、零售、输配电及其他合同费用；不是完整项目净利润。

## 实现与验证

`fetch.py`按散列保存新原件，失败请求另留清单。`build.py`构建价格、频率统计与供体记录、历史事件及参数包。`run.py`从四国已验收滚动流程移植，替换地区、日期、数据和电站来源，数学约束沿用。`scheduling.py`只扩展已审核历史范围至2025年12月和9月1日尾部。主线程执行代码编写。

求解每天优化并冻结截止日前订单，保存不可覆盖的原生账本；固定整数LP不可行的解不能冻结，允许相同数学问题跨求解器复核。可行种子中的网格松弛只用于启发式，必须用真实网格修复；失败则保留已有可行起点，不改变报价或物理可行域。窗口gap门禁0.5%，数值停止阈值0.1%；不意味着全期收益误差界或严格联合全期最优。

V3使用经独立审核的 `daily_solver.py`。在完整日基线和日末固定SOC、原生合同不跨日、服务不跨半小时条件下，各日独立求解；每日EFC不超过原整窗年度剩余额度是全局可行解的必要条件，各日上界之和因此是整窗有效上界。只有拼接年度EFC不超过原额、完整原输入物理审计通过、各日真实数值证书有效时才接受，否则退回整窗MIP。原gate不重写，以`decision_start`保持原时点固定/自由分类，执行与冻结仍按原时钟。局部预算补偿仅用于让局部实际allowance精确等于原整窗allowance；最终恢复原预算、已用和预留记录。正式生产没有报价网格松弛。

28项测试已PASS，包括12月起始截止、跨年采购、3月制度切换、9月观察、分年度预算、整窗/日分解对照、未来日订单仍开放、年度拼接超限回退、单日上下界矛盾不可被他日掩盖，以及现有离线绑定、物理回归和求解重试。初次沙盒测试因Windows不可覆盖文件链接权限报错，使用本地权限重跑通过，未改测试口径。独立审核亦复跑8项定向测试和7种证书判定组合PASS。

输入独立验证PASS：22份原件、9,080个原生块、13,200格（含尾部）逐条价格核验；7,180个代理格供体核验。964格目标负荷超供体范围；留整日外诊断均值MAE0.016414 Hz、尺度MAE0.006599 Hz，仅支持已观测春夏季内诊断，不验证冬季迁移。
