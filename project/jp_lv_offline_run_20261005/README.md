官方来源沿用[已审核离线包](../jp_ev_offline_20261005/README.md)：EPRX FY2025/FY2026一次离线1-1确报、合计确报的四国电源属地平均价及成交量，FAQ字段定义；访问2026-10-05，适用月份及未确认发布日期分别登记。同期四国日前价和频率原始/代理输入沿用已确认版本，不新增市场规则。

规则事实、研究解释与假设见formulation §14.8。无属地成交价证据时不新增报价是保守假设，不是官方禁止投标；均价为区域代理、理想全额成交、无价格冲击，频率缺口沿用代理，恢复购售电按日前价代理。本结果为逐日滚动事后条件现金，不是事前可执行收益或全期联合优化严格上界；不含偏差结算、未建模合同费用、投资、固定运维、衰减更换及税费。
