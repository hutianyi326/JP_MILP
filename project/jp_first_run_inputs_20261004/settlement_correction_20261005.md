## 研究解释与模型范围

当前 LV_FCR 和 HV_SPOT_FCR 明确限定为一次单独中标且不含余力利用合同例外。不能仅凭登记一个 V1/V2 数值打开例外；如需研究该合同须新增经过核验的结算映射。

一次激活现金 Pi_act = 0；上、下认可系数为 0，价格为 null（不适用，不是缺失填零）。容量收入和现货合同现金仍保留。物理响应 r、上下调用电量、实际充放电、SOC、转换损耗、循环预算及服务见证约束均不因现金归零而删除。

无 V1/V2 付款不代表没有偏差结算。当前偏差结算仍未建模，输出显式标记 IMBALANCE_EXCLUDED_NOT_FULL_NET_REVENUE。没有从 ICS 或区域 EDC 单价静默补入结算收益。

复合场景保留已有 DA 上调正系数、下调负系数的经济代理，仅作用于一次计算的联合物理毛电量；不是官方 V1/V2、产品专属结算价或真实项目收入。区域代理价格的方向与合同映射待确认，本次未擅自替换。
