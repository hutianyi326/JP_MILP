## 数据能够支持的研究解释

`regional_30min.csv` 为原始统计及直接单位转换。频率支持一次控制响应映射；既 LFC 动作量及其上下相当值支持 LFC 区域毛量的统计情景；区域运行 A、B、O 等列支持产品份额情景。这些列没有直接给出二次①或三次①的独立历史激活电量。

区域运行表内的 A、B、O 单价和 ICS 限界价格均保留为背景字段，**未标为本站 V1/V2 激活结算价**。日内数据是 JEPX 市场整体统计，未标为四国可成交日内价格；本轮也没有据此启用无限日内交易。

一次 F 行情仍为未分离的一次产品统计，未反推出专属在线均价；C 行情是综合复合统计，不是二次①加三次①特定组合的独立成交均价。F 与一次离线存在包含关系，不能相加为两个独立容量池；C 与各产品也不能在没有去重规则时相加作参考容量。

## 尚未作为正式输入的建模假设

仅为使已有数学方法可复查，本轮生成 LFC 区域敏感性候选：令 `m` 为既 LFC 平均动作 MW，`s=κ(U−L)/4`，计算 `G上=0.5H(m,s)`、`G下=0.5H(−m,s)`。其中 `H(m,s)=sφ(m/s)+mΦ(m/s)`，在 `s=0` 时定义为 `max(m,0)`。每格均检验 `G上−G下=0.5m`。

候选分别取 κ 为 0.5、1、1.5，并暂以原数值正号代表上调。这是**未校准、未冻结的敏感性建议**，不是由相当值证明的标准差，更不是日本官方规定；没有将任何一个值设为生产默认。文件名和每行状态均明确其不可直接进入正式模型。

候选表中的产品归属份额、上下方向参考容量、alpha 均留空。缺分母不能输出本站激活系数；不能拿本站优化中标量作分母，也不能将市场上调采购量直接复制成下调能力。FCR 控制参数和最终联合状态仍在正式运行配置完成后生成。
