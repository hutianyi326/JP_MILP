# 日本EPRX指令口径与复合控制研究

研究日期：2026年10月1日。适用基准：2026年7月1日实施的 EPRX 取引規程 v18、取引ガイド v10，以及2026年3月14日实施的揚水蓄電池ガイド。研究范围：一次、二次①、二次②、三次①及其复合约定；三次②仅在必要的边界比较中出现。

本文使用三个标识：**规则事实**表示官方文本直接支持；**研究解释**表示从规则和控制原理推导的含义；**建模假设**表示供模拟使用、尚不能当作实际设备接口的条件。尚未公开确认的设备级参数写为**待确认**。页码一律为 PDF 从1起的页序，另列印刷页时特别注明。

## 1 核心结论

**不能按照产品名称，把一次到三次①统一归为增量指令，也不能统一归为绝对出力指令。需要同时识别产品功能、参入资源形式、通信方式、属地区域以及余力活用合同。**

| 产品 | 规则事实及可确认的指令口径 | 不能据此作出的推断 |
|---|---|---|
| 一次 | 本地检测频率偏差并按调定率响应，TSO不发送该产品的实时出力指令。控制响应可表达为对工作点的功率调整 | 不能说TSO发送了“一次增量MW指令”；实际工作点也不能一律认定等于日前计划 |
| 二次① | LFC。单独发电机的出力調整指令为实出力目标；出力変化量指令为相对参考的调节目标；接点指令为上升/下降脉冲，按事先约定的每脉冲目标值解释。接收功能须与属地TSO协商 | 不能把所有LFC数值看成独立增量；不能把一个接点脉冲直接当成1MW |
| 二次② | EDC。单独发电机可存在实出力目标、变化量目标或接点形式；各リスト・パターン按出力变化量接收。具体可用形式受通信和属地条件限制 | 不能把EDC数值4MW直接解释为“在现有出力上再增加4MW” |
| 三次① | 同样为EDC，沿用上述语义分类；与二次②的主要区别包括响应及指令时间安排 | 不能认为它天然拥有一条与二次②独立、可再次叠加的EDC激活信号 |
| 复合 | 第35条直接指向别表3；一次仍自端控制，LFC与EDC按属地方式合并或分别发送。二次②与三次①同中标时，两者指令适用二次②第35条 | 复合不是新增一种全国统一的“复合增量MW”协议，也不意味着每个内数产品均可独立满额后相加 |

证据：S02本则第13条、各别册第35条、别表2与3；S03 pp175–177、207–209、239–245、397；S04 pp20–23；S05指令与运用问答。具体定位和官方链接见第12节。

这里的“实出力目标”是**相关受控对象和约定计量端口的功率水平**。在单独放电、单独充电、充放电一体以及聚合资源间，端口和正负号可能不同，不能直接等同于统一的电站净放电MW。

## 2 需要区分的三个维度

### 2.1 功率目标的参考原点

**研究解释。**统一用向电网注入为正的电站净功率 (p(t))，无调节参考功率 (b(t))，上调激活 (a(t))。

\[
p(t)=b(t)+a(t). \tag{1}
\]

绝对目标 (u^{abs}(t)) 表示指定端口应达到的功率水平；将端口、单位和正负号转换后：

\[
p^{*}(t)=u^{abs}(t),\qquad a^{*}(t)=u^{abs}(t)-b(t). \tag{2}
\]

相对目标 (u^{rel}(t)) 表示相对指定参考的调节功率：

\[
a^{*}(t)=u^{rel}(t),\qquad p^{*}(t)=b(t)+u^{rel}(t). \tag{3}
\]

式(2)(3)是统一坐标下的定义，不是任何电站协议的逐字规定。没有完成端口转换前，应使用其原始端口变量，不能直接套用电站净功率。

**例。**计划放电2MW，绝对指令4MW意味着目标放电4MW、相对计划上调2MW；变化量指令上调4MW意味着目标放电6MW。相同的数字“4”会产生不同电量。

### 2.2 变化量目标与逐次增减动作

**研究解释。**“出力変化量指令”中的变化量通常是相对计划或基准的**目标调节水平**。若参考为2MW，连续两次下发相对目标1MW，保持的目标是3MW，不会自动变成4MW。

接点脉冲则是增减动作编码。它需要初始状态、每脉冲对应量、延迟、保持/复位及限幅规则。一个用于说明的解码模型是：

\[
x_k=x_{k-1}+\gamma_{+}n_{+,k}-\gamma_{-}n_{-,k}. \tag{4}
\]

(n_{+,k},n_{-,k})为该区间内增减脉冲数，\(\gamma\)为MW/脉冲，\(x_k\)为解码后的目标状态。**建模假设：**式(4)仅描述一种离散累计实现，真实实现须按设备与TSO约定；不得默认同一\(\gamma\)、相同正负变化速度或无限累计。S03 p241的官方图示直接支持“先约定每脉冲目标值，再按换算出的指令量响应”，但没有公开所有电站的完整状态机。

尤其不能把“每个脉冲的增量”与“相对计划的目标调节量”混为同一类数据。

### 2.3 合并发送与分别发送

**规则事实。**S02别表2注1将TSO对EDC与LFC演算结果合算后发送称为“一括”，分别发送称为“個別”。这描述的是合成位置，不单独定义参考原点。S05确认，分别发送的区域需要调节力提供方完成合算。

**研究解释。**合并发送时收到的数值或接点已经表达了中央控制部分的合成目标，不能再重复增加一遍LFC或EDC。分别发送时也必须先解码到兼容坐标，再按协议合成；“需要合算”不等于直接把两个报文数字做加法。

## 3 一次的口径

**规则事实。**S02一次别册第35条，PDF p310、印刷p296，明确以属地频率偏差和资源调定率开展调节，TSO不发送该产品指令。因此问题应表述为“一次控制产生多少功率变化”，而不是“一次下发的MW是绝对还是增量”。在线监视也不改变一次自端控制的性质。

**研究解释。**一次产生的是围绕工作点的频率响应。储能在充电时，上调可能先表现为少充电；在放电时表现为多放电。与LFC/EDC同时运行时，工作点可能随中央目标变化，具体协调逻辑仍须设备级确认。

**建模假设。**可以用已标定的频率响应函数描述：

\[
a_{GF}^{*}(t)=g\big(f(t-\tau_{GF})-f_0;\theta_{GF}\big),\qquad
p^{*}(t)=p_{work}(t)+a_{GF}^{*}(t). \tag{5}
\]

\(f\)为Hz，\(\tau_{GF}\)为延迟，\(\theta_{GF}\)包括调定率、不感带、容量限制和设备响应。一个连续死区的简化线性示例为：

\[
g(\Delta f)=\operatorname{clip}\left[-K\operatorname{sgn}(\Delta f)
\max(|\Delta f|-d,0),-R_{GF}^{down},R_{GF}^{up}\right]. \tag{6}
\]

\(K\)单位MW/Hz，\(d\)单位Hz。式(6)不是全国统一储能控制公式；特别是死区边缘行为、上/下调限制、异常时响应和工作点选取，不能仅从中标容量推定。商业上采购上调容量，也不意味着实际频率控制数据只能取正值。

## 4 二次①的口径

### 4.1 单独资源的数值指令

**规则事实。**S03 p239注3及p397注2明确：对单独发电机采用实出力指令时，以发送的实出力指令值与实出力实绩进行评价。S02二次①事前审查条款也单列出力調整指令，见PDF pp229–230；S04 pp21–23对应栏以计测功率或净计测功率上送。

**研究解释。**对该明确分类的单独资源，“出力調整指令（数値指令）”应按受控对象的绝对实出力目标解释，不能将它自动当作LFC调节增量。例如计划2MW、LFC实出力目标3MW，单独运行时上调为1MW，而不是3MW。

这里确认的是**实出力指令的语义**，不是证明“所有区域所有LFC报文字段都等于电站净出力”。本则第13条对二次①的接收功能明确留给属地协商；在LFC与EDC分别发送并共同运行时，LFC通道的零点、偏置与参考切换仍需要项目接口资料。

### 4.2 变化量指令与聚合资源

**规则事实。**S02本则第13条对各リスト・パターン规定接收出力变化量指令；单独发电机的二次①接收要求须与属地TSO协商。S03 p397将出力变化量与数值实出力评价区分开；S04 pp21–23给二次①列出了变化量指令对应的计量方式。

**研究解释。**确认采用变化量指令时，目标为相对其指定计划/基准的调节水平。对于聚合资源，TSO指令首先对应整个申报pattern，聚合商再分配到电池。不能把pattern指令值直接给每台电池，或把pattern级变化量当作每台电池绝对功率。

### 4.3 接点信号

**规则事实。**S03 p241明示事前审查时由提供者和属地TSO约定每脉冲目标值。S02二次①第35条，PDF pp247–248，规定接点评价用约定目标换算，并允许在相关不适合情形下应提供者请求事后披露指令值。

**研究解释。**接点是第三类，应标记为“增减动作编码”，再解码成绝对或相对目标。S04允许二次①反馈原始计测功率，也允许反馈扣除属地周期计划后的功率。这并不矛盾：反馈可由TSO再转换；仅看到上送的计测值，不足以反推出下发报文零点。

## 5 二次②与三次①的口径

**规则事实。**S02本则第13条，PDF pp34–35：专线单独发电机一般接收数值出力调整或接点增减，pattern接收变化量；简易指令单独发电机可选择数值出力调整或变化量，pattern接收变化量。简易指令单独发电机签订余力活用合同时，限定接收数值出力调整。实际可用接口还受属地系统改造和接入限制影响。

S03三次① pp175–177与二次② pp207–209分别示意实出力、变化量两种口径，并说明单独发电机的实出力指令直接与实出力比较。S02二次②第39条PDF p207还将变化量的指令量与实出力指令值分开，并对后者的余力范围评价使用计划电力加约定容量的界限。这共同支持：**数值出力调整是功率水平；变化量是相对参考的调节水平。**

**研究解释。**二次②与三次①属于同一个EDC控制功能家族。二次②的5分钟与三次①的15分钟要求，不会把相同类别的报文从绝对目标变成增量目标。响应时间、目标时刻和出力参考原点是不同属性。

**规则事实。**接点EDC存在隐藏的数值目标。S02三次①第35条PDF p144及二次②第35条PDF p196规定，评价可使用TSO生成接点指令时的目标数值，并在相关不适合情形下依请求披露。**研究解释：**不能仅凭接点脉冲数量和中标容量完整恢复EDC目标；必要时还需TSO目标记录及状态。

### 5.1 指令周期取决于资源与合同

| 场景 | 二次② | 三次① | 来源 |
|---|---|---|---|
| 简易指令 | 指令间隔5分钟，按5分钟到达安排，含初始/连续块特殊处理 | 指令间隔5分钟，按15分钟到达安排，含初始/连续块特殊处理 | S02 PDF pp143、195 |
| 专线且单独发电机有余力活用合同 | 采用别表2的属地EDC周期或条款规定的另一指令方式 | 同左，但相应到达安排不同 | S02 PDF pp144、195–196 |
| 专线且单独发电机没有余力合同，或pattern | 第35条所列方式为发送后5分钟到达、指令间隔5分钟 | 发送后15分钟到达、指令间隔5分钟 | 同上 |
| 与其他功能同中标或复合约定 | 先按别表3确定适用条款；含LFC与EDC的组合须属地协商 | 同左 | S02 PDF pp340、363 |

**研究解释。**不能把别表2中的秒级EDC发送周期直接套给所有储能，更不能由“专线接入”推定具有余力合同。也不能把三次①15分钟要求解释为每个目标都必须保持15分钟。

### 5.2 新指令缺失与提供期结束

**规则事实。**S02二次②/三次①简易指令第35条区分“维持上一指令”“最初未下发则按计划/基准运行”“提供期结束”三种情况。S03 p242的二次①试验说明也要求未有新指令时维持此前指令；实际运行应结合适用第35条与属地约定。

**研究解释。**推算指令时，必须保留生效、修改、取消和终止时间。缺失记录不等于零值，保持上一目标也不意味着其跨提供期无限延续。不得用采样缺测直接触发激活归零。

## 7 复合产品的口径

### 7.1 复合约定不新增第五种控制功能

**规则事实。**复合约定的四个成员产品对应三个功能：一次GF、二次①LFC、二次②及三次①EDC。S02复合第22/24条，PDF pp329–332要求成员能力及合成指令追踪能力；复合第35条PDF p340规定按别表3指令。

**研究解释。**复合是共享能力的约定和评价机制。中央控制仍由LFC/EDC接口实现，GF仍由本地频率触发。不存在可以不看属地接口就统一使用的“复合报文口径”。“合成指令信号”也不能解释为TSO已把一次实时频率响应一并计算进了中央报文。

### 7.3 合成数学表达与确定性边界

下面给出统一坐标的**研究解释和条件性公式**；这些公式不是公开规程已经给出的每家TSO源代码。

先对每个独立中央通道进行端口、量纲和参考转换，获得其真实独立贡献，再合成：

\[
a_C^{*}=\mathcal C\big(u_{EDC},u_{LFC};\theta_C,b,state\big). \tag{7}
\]

\(\theta_C\)包括信号是否已含另一通道、参考原点、脉冲换算、插值、功能锁定和合同配置。

| 已确认的接口语义 | 可用表达 | 必要条件 |
|---|---|---|
| 两个独立相对贡献 | \(p_C^{*}=b+a_E+a_L\) | 两者贡献独立，共用参考未重复计入，无其他协调修正 |
| EDC绝对工作点加LFC独立偏差 | \(p_C^{*}=u_E^{abs}+a_L\) | 协议明确LFC偏差围绕EDC工作点叠加 |
| 两个通道各自含相同参考 | \(p_C^{*}=u_E^{abs}+u_L^{abs}-b\) | 协议确认二者分别等于\(b+a_E\)、\(b+a_L\)，且贡献可加 |
| TSO已合成的绝对目标 | \(p_C^{*}=u_C^{abs}\) | 不再添加已包含的LFC或EDC |
| TSO已合成的相对目标 | \(p_C^{*}=b+u_C^{rel}\) | 不再添加已包含的LFC或EDC |
| 合成接点或分别接点 | 按约定解码器产生\(p_C^{*}\) | 不能把脉冲与MW直接相加 |

第一行至第三行的实际适用性必须有协议证据，不能仅由产品或区域名称选择。特别是两个绝对报文的第三行，只是一种可解释的参考结构，**并非已确认东北所有电站都采用该式**。

若一次同时参与，则在已经确认协调逻辑的条件下：

\[
p^{*}=\mathcal F\big(p_C^{*},f;\theta_{GF},\theta_C\big). \tag{8}
\]

简单的\(p^{*}=p_C^{*}+a_{GF}\)只是一种建模假设。实际可能具有工作点调整、GF/LFC功能排除、限幅和其他协调，须在模型中登记。

## 8 储能的充放电端口与评价口径

**规则事实。**S04 pp20–23分别处理单独发电、需求侧充电、发电与需求一体。pp21–23注明属地符号可能不同，二次①/一次瞬时供出电力须协商。以下是统一中文记号下对官方计算关系的整理，省略的其他参入条件仍须查原表。

定义\(G\)为补正计测放电/发电功率，\(D\)为补正计测充电需求功率，均按原端口正量记录；\(G^0\)为发电计划，\(B_D\)为事前预测充电基准，\(H\)为需求抑制计划。均为MW，且使用该产品对应的时间分辨率。

| 资源形式 | 数值出力调整对应的上送量 | 变化量指令对应的EDC上送量 |
|---|---|---|
| 单独发电型 | \(G\) | \(G-G^0\) |
| 需求侧充电型 | \(D\) | \(B_D-D-H\) |
| 发电与需求一体 | \(G-D\) | \(G-G^0+B_D-D-H\) |

**研究解释。**表中是**反馈/评价量**，不能把公式名“瞬时供出电力”一律翻译成“已经扣掉基线的激活MW”。数值出力调整一栏中可能仍含计划功率。充电需求端口的数值下降才对应向电网方向上调。

对需求侧充电，若约定绝对充电目标\(D^{*}\)，则统一净功率\(p^{*}=-D^{*}\)。若单独忽略\(H\)并采用\(B_D=3\)MW，变化量上调1MW对应\(D^{*}=2\)MW、\(p^{*}=-2\)MW，即少充电1MW。变化量上调4MW若允许跨零并以一体资源执行，则由计划充电3MW转为放电1MW；是否允许如此参入与计量，须按S04的资源分类，不能在纯需求资源约定中直接假定。

进一步，**商业调节电量、考核基准与SOC物理能量不是同一量**。模型必须用实际充放电功率更新SOC，用对应结算基准计算调节电量；不能因为数值目标4MW就认定产生4MW的调节贡献。

## 9 对此前4MW与1MW算例的修正

**建模假设。**忽略爬坡、延迟和损耗，仅考察两段完全重叠的目标区间：LFC持续10秒，EDC持续180秒。以下都是口径说明，不是对某家TSO真实指令的断言。

| 已确认或假设的口径 | 参考\(b\) | 重叠10秒内净目标 | 重叠期上调 |
|---|---|---|---|
| EDC独立相对上调4＋LFC独立相对上调1 | 0 | 5MW | 5MW |
| EDC绝对4＋独立LFC偏差1 | 2MW | 5MW | 3MW |
| EDC绝对4，LFC绝对3；两者均含参考2，且确认贡献可加 | 2MW | \(4+3-2=5\)MW | 3MW |
| TSO已合成绝对目标4，其中已包含LFC | 0 | 4MW | 4MW |
| TSO已合成绝对目标4，其中已包含LFC | 2MW | 4MW | 2MW |
| 只有“EDC报文4、LFC报文1”，参考和编码未知 | 未知 | 不能确定 | 不能确定 |

第一行的相对上调电量为：

\[
E^{act}=\frac{5\times10+4\times170}{3600}
=0.202778\ \mathrm{MWh}. \tag{9}
\]

第二行按相同目标持续区间且参考2MW保持，得到：

\[
E^{act}=\frac{3\times10+2\times170}{3600}
=0.102778\ \mathrm{MWh}. \tag{10}
\]

式(9)(10)不同，仅源于EDC数字4的语义不同。因此，最早直接算出5MW及0.202778MWh的结果，只能保留为“两条独立相对贡献”的条件性算例。

**规则事实与解释。**四个内数产品各4MW对应复合容量4MW，并不因此变成16MW。也不能仅凭上述条件性相加认定TSO确实要求5MW，更不能据此直接判定未达标。应使用真实合成目标、功能响应时间、约定和余力范围，以及复合第39条的联合评价。无余力合同时第39条(4)的排除条件是超出第26条产品要件的指令，不是任何“某数字大于4”都自动排除。S02 PDF pp349–355。

反过来，复合容量4MW也没有提供一个可以随意把所有解码目标\(\min(\cdot,4)\)截断的通用操作许可。数值目标是否含参考、是否指令余力、是否超出产品要件，需要分别判断。

## 10 对MILP与激活推算的建议

**研究建议。**第一版沿用联合历史回放方向，但将激活对象从“四条按产品独立采样的功率”改为**同一资源的中央控制目标与本地频率响应**。目前公开数据不能唯一反推出电站级指令，输出应保持情景性质。

建议的数据处理顺序是：原始指令或情景→确认资源/协议→解码→参考和端口转换→按共享功能合成→生成实际功率响应→积分电量→进入SOC与交易优化。可在优化外完成的解码、插值及时间积分先预处理，不需要为每个报文增加MILP整数变量。

| 必须登记的字段 | 含义及防错目的 |
|---|---|
| `area`, `resource_id`, `pattern_id`, `participation_type` | 区分单独资源、需求/发电/混合pattern，避免聚合指令重复下发 |
| `delivery_time_jst`, `sent_time`, `effective_time`, `target_time`, `end_time` | 区分发送与到达时刻，避免未来指令和提供期结束错误 |
| `contract_has_surplus`, `connection_type`, `rule_version` | 选择实际适用的第35条与专线/简易方式 |
| `control_group`, `contains_edc`, `contains_lfc` | 标记共享EDC及合成中央信号，避免重复计入 |
| `encoding` | `absolute_level`、`relative_level`、`contact_action`，不得仅标numeric |
| `unit`, `port`, `positive_direction`, `scale` | 统一kW/MW、发电端/送电端、需求正号/净注入正号 |
| `reference_id`, `reference_value`, `reference_resolution`, `reference_published_at` | 记录参考原点、时间分辨率和可获知时间 |
| `pulse_value`, `initial_state`, `reset_rule`, `hold_rule` | 接点解码及缺指令处理 |
| `interpolation_rule`, `ramp_rate`, `delay`, `function_enable` | 描述实际响应而非假设理想矩形脉冲 |
| `evidence_id`, `agreement_section`, `confidence` | 支持规则事实、协议待确认与情景假设的追溯 |

**建模假设。**如果缺少电站接口，只能建立明确标记的绝对合成、相对合成或独立贡献情景；不能把某情景宣称为日本统一规则。二次②/三次①共享EDC应先建一个控制功能情景，并按产品容量/响应要求施加能力限制；产品级激活拆分若无识别数据，应标记不可识别。

物理能量关系用于说明为何必须统一口径：

\[
E_{t+1}=E_t+\eta_c\int_t^{t+\Delta t}[-p(\tau)]_+d\tau
-\frac{1}{\eta_d}\int_t^{t+\Delta t}[p(\tau)]_+d\tau . \tag{11}
\]

时间积分以小时计。式(11)积分实际充放电功率，不能用30分钟净激活电量替代双向充放电分别积分，尤其在LFC高频过零时。结算调节量还需另按结算基准计算；本文不冻结新的结算规则。

## 11 未解决的设备级问题

全国公开规则足以确认各类口径的存在、九区域列示方式以及复合适用条款，但尚不能唯一恢复所有电站的逐字节接口。以下项目明确保留为待确认：

1. 东北个别数值通道共同运行时，LFC数字是否带独立基准、如何随EDC工作点调整。现行别表2仅确认发送形式，别表3要求属地协商，不能虚构统一扣基线公式。
2. 东京、关西以及中部接点接口的每脉冲量、初始状态、复位、连续接点及限幅行为。指南确认协商机制，但未公开某独立储能的标定值。
3. 独立储能实际采用单独发电、需求侧还是一体参入，收到的数值对应净功率、放电功率还是充电需求功率，以及发电端/送电端换算。
4. 该站是否签余力合同、是否适用别表2全部周期、混合产品时具体适用的指令安排和功能排除规则。
5. GF叠加中央目标时的工作点、SOC恢复和限幅协调；不能仅凭复合约定最大容量推定完整控制算法。

用于关闭这些问题的材料包括：属地給電申合書、信号收发一览/点表、通信接口说明、事前审查结果与接点标定记录、合成追踪试验记录、同一时间轴上的计划与原始下发/上送日志。优先选取一个非零计划功率的试验段，以区分绝对与相对目标；零计划下两种口径数值可能完全相同。

**研究解释。**本次查到的四国官方工事说明S06确认，接入须落实具体案件的通信工事与试验，部分电源还受中给系统改造制约。它不公开储能报文字段，不能用其补齐上述参数。OCCTO/送配电网协议会2024年通信规格统一意见募集资料S07说明既有区域方式存在差异；这是未来系统的研究资料，不能拿未来IEC61850草案当作2026年全部电站的现行协议。
