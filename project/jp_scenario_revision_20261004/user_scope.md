# 日本MILP测算场景调整

日期：2026-10-04。性质：用户测算范围与建模假设调整，不是日本官方规则变化。

## 用户要求

> 我决定改变MILP的计算场景，首先针对LV的项目，因为只参与一次调频，激活量也没有收入，这部分可以忽略；针对高压项目，从测算场景上我要固化成2种，一种是现货+一次1；另一种是现货+2次1+三次1；因为从之前的对话来看，这两种是最优可能组合的模式

## 已明确范围

- LV的辅助服务参与范围仍仅一次；本次要求简化其激活部分。
- 高压项目固定为两个分别求解和比较的场景：现货＋一次；现货＋二次①＋三次①。
- “一次1”按一次调频理解，不新增“一次①”产品类别。
- 用户所称高压项目沿用当前文档EHV计算实例标签及既有规模；本次没有改变电压资格、MW/MWh或设备参数。
- 两个高压场景为用户选定候选策略，尚未穷举证明是全体组合的最优解。模型只比较这两个范围内的结果。
- 保留原始研究和历史规则，不删除不再进入本轮场景的二次②/三次②研究。

## 用户已回复确认的口径

1. “只忽略激活收入，仍估算调用电量对SOC、损耗和循环的影响”。LV不得将物理激活系数设为零来简化数据需求。
2. “作为复合产品投标，两个产品容量允许不同并由模型优化”。解除旧M4固定比例复合模式限制，分别定义二次①、三次①容量决策。

两项均为2026-10-04用户明确回复，无临时等容量或省略物理激活假设。主线程按本次授权批准修改countries/JP下的数学文档、接口及入口说明。

## 交付边界

本轮更新数学文档与输入依赖、入口说明。不实施生产代码或历史收益计算，不将旧独立审核PASS覆盖本次范围变更。用户本轮未要求新增独立审核，主线程不主动委派。
