## 已有数据及零值注意事项

在当前标准化F、C行情中，各有1,436格满足source中标量正且均价为数值，1,438格满足TSO中标量正且均价为数值。其余格不能因为均价数字为0就当作本站可靠的零结算价。采用哪个口径应由资源池和价格代理定义决定。

LFC文件末尾48行全空白是模板行；不是日期缺失的真实激活，也不是7月1日样本。三类区域文件核心半小时主键均完整；ICS部分字段状态另行处理。
