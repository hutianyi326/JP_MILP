## 规则事实 研究解释与建模假设

规则与原始事实：容量行情保留2026年3月14日前后的原生块长变化。历史版本分别按S3、S4、S5、S6登记，见[既有历史规则链](../../countries/JP/topics/history_settlement_revision_20260928.md)。本轮不重新定义历史申报窗口，也不把六月D-1时钟强加到年初。价格从JPY/kW/30min乘1,000转为JPY/MW/30min；三小时块展开时不重复除以6或乘0.5。

研究解释：数据有数值不等于本站能够按该价成交；中标量为零时价格候选为空，不把原始零价格作为可成交价。区域净电量不能直接认定为各产品毛激活电量。源时间格解释为日本交付时区Asia/Tokyo，所有输出显式带+09:00，时间戳为区间起点。

建模假设：统计宽度代理为(U−L)/4，不宣称真实标准差。异常整日隔离属于质量处理假设。所有产品激活系数、复合参考能力和付款映射仍待正式绑定；没有把六月统计归一分母推广至全年。一次单独中标且不含余力合同例外的激活现金为零，物理响应仍需估算。偏差结算未建模，价格背景不可静默代替结算映射。

本包全部是事后数据，并非决策时可见输入。没有预测/事后混用，也没有真实策略收益结论。

## 后续测算门槛

除了电池和控制参数、经核验的复合完整内数菜单，还需明确以下事项：

1. 1月至4月28日前以及异常日的激活统计：取得有效资料，或单独批准有来源、带不确定性的替代情景；不能自动用六月均值回填。
2. 8月31日观察尾部：取得有效统计或明确替代/边界方案；不能因8月30日是正式末日而忽略。
3. 选择历史规则回测还是明确的统一制度反事实情景，并实现相应原生交易块及申报时钟。当前六月组装器硬编码1,488格和D-1时钟，不接受本扩展包，也不应直接修改行数后使用。
4. 正式期首日前已有承诺或准备期、扩展期归一/敏感性和预算绑定，以及结算缺口仍需处理。当前文件不生成model_input.json，以避免误送正式求解。

可连续使用的统计区间为4月28日13:00至7月31日00:00，以及8月1日00:00至8月31日00:00。两段之间不能删除缺失日后直接连接SOC，单独测算也需要各自的初末状态和观察期处理。
